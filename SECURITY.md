# Security Policy

## Supported Versions

We release security updates for the latest stable version of this project. Please ensure you are running the most recent release.

## Reporting a Vulnerability

If you discover a security vulnerability in this repository (Healthcare Insurance Data Analysis System), please report it in a responsible manner:

- **Do not** file public GitHub issues for security problems.
- Instead, email the maintainers at [security@brainsait.io] with details about the vulnerability.
- Please include:
  - A clear description of the issue.
  - Steps to reproduce or proof-of-concept code.
  - The impact and any known mitigations.

We will respond within 5 business days and keep you informed as we investigate and address the issue.

## Disclosure Policy

- We aim to resolve valid security issues as quickly as possible.
- Once a fix is ready and released, we will publicly acknowledge the researcher (unless anonymity is requested).

## Best Practices

- Keep your dependencies up-to-date (see our [dependabot](.github/dependabot.yml) configuration).
- Never share sensitive data (such as patient or insurance information) in public issues or pull requests.
- Use strong authentication and enable 2FA on your accounts.
- For more security guidance relevant to healthcare insurance data, review applicable regulations (e.g., HIPAA, GDPR).

## Contact

For urgent security matters, please contact: [security@brainsait.com]

Thank you for helping make this project safer!
